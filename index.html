C.A.T.S.

Una herramienta para construir juntos el concepto de una partida de rol.

Acceso a C.A.T.S.

Inicia sesión o crea una cuenta para crear salas y participar. El generador aleatorio sigue disponible sin cuenta.

Sesión iniciada

Configurar nombre de jugador

Elige el nombre que aparecerá en las salas y junto a tus respuestas.

Preparar una partida

Crea una sala y comparte su enlace de invitación. Quienes tengan el enlace podrán unirse.

Crear una sala

Primero crea la sala. Después podrás indicar tu nombre y el juego desde su interior.

Unirse a una sala

Para entrar, abre el enlace de invitación que te compartió el anfitrión. La sala se abrirá automáticamente con tu nombre de jugador.
